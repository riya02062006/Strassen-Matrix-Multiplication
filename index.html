Algorithm overview

Strassen divides each matrix into four blocks and computes seven recursive products instead of eight. It combines these products to construct the result.

Conventional multiplication: O(n³)

Strassen multiplication: O(nlog₂7) ≈ O(n²·⁸⁰⁷)

For small matrices, JavaScript overhead can outweigh the theoretical speed advantage.
